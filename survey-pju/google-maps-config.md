# Google Maps

Dashboard Survey PJU sudah disiapkan untuk Google Maps.

Sebelum peta tampil, isi `googleMapsApiKey` pada `index.html` dengan API key Google Maps Platform.

Aktifkan Maps JavaScript API pada Google Cloud dan batasi API key ke domain GitHub Pages Anda. Google Maps JavaScript API membutuhkan API key dan billing aktif. https://developers.google.com/maps/documentation/javascript/get-api-key
