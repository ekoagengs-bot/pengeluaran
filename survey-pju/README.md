# Survey PJU Bima & Dompu

Dashboard web untuk monitoring survey PJU Kabupaten Bima, Kabupaten Dompu, dan Kota Bima.

## ULP
- ULP Sape
- ULP Dompu
- ULP Woha
- ULP Bikot

## Database
Google Spreadsheet:
https://docs.google.com/spreadsheets/d/1IhB-agDYb7WcVSnZioHRWYE9Hm2iQLsJdA72E9jlXWY/edit

Dashboard membaca tab `PJU_Survey` melalui Google Visualization API. Pastikan tab tersebut ada dan data dapat dibaca oleh pengguna yang membuka dashboard.

## GitHub Pages
Project ini ditempatkan di folder `survey-pju/` dalam repository `pengeluaran` agar aplikasi lama di root repository tidak terganggu.

URL target:
`https://ekoagengs-bot.github.io/pengeluaran/survey-pju/`

## Fitur
- Statistik total PJU
- Rekap 4 ULP
- Filter wilayah dan kondisi
- Peta titik GPS survey
- Batas administrasi pada peta
- Tabel survey terbaru
- Ekspor CSV
